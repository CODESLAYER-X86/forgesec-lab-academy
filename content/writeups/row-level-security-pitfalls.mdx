## Context

In modern client-connected databases, relying on frontend visibility toggles leaves underlying tables exposed to direct API queries.

## Secure Separation Pattern

1. Enable Row Level Security (`ALTER TABLE ... ENABLE ROW LEVEL SECURITY`) on every exposed user table.
2. Separate sensitive grading secrets (such as `quiz_answer_keys`) from readable question/option tables.
3. Revoke `anon` and `authenticated` privileges on sensitive tables and evaluate grades strictly inside server-side functions or Server Actions.

## Key Takeaway

Authorization must be enforced at both the application server boundary and the database policy layer.
