## What You Will Learn

- Define an origin (`scheme + host + port`) under the browser Same-Origin Policy.
- Configure `Content-Security-Policy` to constrain script execution and framing.
- Test header policies safely on local test endpoints.

## Core Browser Defenses

| Header | Primary Protection |
| --- | --- |
| `Content-Security-Policy` | Restricts allowed script, style, and frame sources |
| `X-Content-Type-Options: nosniff` | Prevents MIME-type confusion attacks |
| `Referrer-Policy` | Controls referrer URL leakage across origins |
| `Strict-Transport-Security` | Enforces HTTPS on subsequent visits |

```text
Content-Security-Policy: default-src 'self'; frame-ancestors 'none'; object-src 'none';
```

## Summary

Defense in depth pairs strict server-side input sanitization with browser-enforced policies like `Content-Security-Policy` and `SameSite` cookies.
