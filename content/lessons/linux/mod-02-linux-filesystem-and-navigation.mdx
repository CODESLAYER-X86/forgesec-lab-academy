# **Module 02 — Linux Filesystem and Navigation**

## **A. Welcome to the Linux Filesystem**

Every operating system needs a way to organize and store information. Linux uses a **filesystem** to organize files and directories.

A filesystem is the structure Linux uses to store, arrange, and access information.

Think of it like a filing cabinet:

- The cabinet represents the entire filesystem.
- Drawers represent directories.
- Folders inside drawers represent subdirectories.
- Documents inside folders represent files.

Linux organizes its files and directories in a hierarchical structure, meaning directories can contain other directories and files.

Understanding this structure is important in cybersecurity because you will regularly need to:

- Navigate through system directories.
- Locate configuration files.
- Explore application files.
- Find system logs.
- Identify files that may be relevant during security investigations.

Let's start exploring.

## **B. Understanding the Linux Directory Structure**

### **1. The Root Directory&#x20;**`/`

Linux organizes its entire filesystem under one main directory called the **root directory**.

It is represented by:

```
/
```

Think of `/` as the starting point of the Linux filesystem.

Unlike Windows, where you might see separate drives such as `C:\` or `D:\`, Linux presents its filesystem through a single directory hierarchy.

Directories, files, and other storage locations are organized under `/`.

### **2. Important Linux Directories**

You don't need to memorize every Linux directory right now. Start by recognizing these important locations.

| Directory | Basic purpose                                                                                                           |
| --------- | ----------------------------------------------------------------------------------------------------------------------- |
| `/`       | Root of the entire filesystem.                                                                                          |
| `/home`   | Contains regular users' home directories.                                                                               |
| `/root`   | Home directory of the root (administrator) user.                                                                        |
| `/etc`    | Contains system configuration files.                                                                                    |
| `/var`    | Contains variable data, including system logs.                                                                          |
| `/tmp`    | Stores temporary files.                                                                                                 |
| `/usr`    | Contains many user-space programs and resources.                                                                        |
| `/bin`    | Contains essential user commands. On modern distributions, this may be linked to `/usr/bin` through merged directories. |
| `/dev`    | Contains device files representing hardware and virtual devices.                                                        |

**Important distinction:**

- `/` is the root of the entire filesystem.
- `/root` is the home directory of the root user.
- `/home` contains the home directories of regular users.

These are three different things.

**Tip:** In cybersecurity practice, `/etc` and `/var` are particularly useful directories to become familiar with because they commonly contain configuration files and logs.

## **C. Absolute Paths vs Relative Paths**

Before navigating through Linux, you need to understand paths.

A **path** is the location of a file or directory in the filesystem.

Linux uses two main types of paths.

### **1. Absolute Paths**

An absolute path specifies the complete location of a file or directory, starting from the root directory `/`.

For example:

```
/home/student
```

Another example:

```
/etc/passwd
```

Both paths begin with `/`, so they are absolute paths.

An absolute path identifies a location regardless of your current working directory.

### **2. Relative Paths**

A relative path describes a location based on your current working directory.

For example, imagine your current location is:

```
/home/student
```

You want to access a directory named `Documents` inside your current directory.

You can use:

```
cd Documents
```

You don't need to provide the complete path because Linux understands that `Documents` is inside your current location.

### **3. Understanding&#x20;**`/`**,&#x20;**`~`**,&#x20;**`.`**&#x20;and&#x20;**`..`

These symbols are frequently used when navigating Linux.

| Symbol | Meaning                             |
| ------ | ----------------------------------- |
| `/`    | Root directory of the filesystem.   |
| `~`    | Home directory of the current user. |
| `.`    | Current directory.                  |
| `..`   | Parent directory (one level above). |

Let's look at a practical example.

Suppose your current directory is:

```
/home/student/Documents
```

To move one directory upward:

```
cd ..
```

Your new location becomes:

```
/home/student
```

To return to your home directory from anywhere:

```
cd ~
```

To refer to the current directory:

```
.
```

To refer to the filesystem root:

```
/
```

**Remember:** `/` and `~` are not interchangeable. `/` represents the entire filesystem's root, while `~` represents your current user's home directory.

## **D. Essential Navigation Commands**

Now let's learn the commands you will use to explore the Linux filesystem.

You don't need to memorize everything immediately. Execute each command and observe what happens.

### **1.&#x20;**`pwd`**&#x20;— Print Working Directory**

The `pwd` command displays your current location in the filesystem.

**Syntax:**

```
pwd
```

**Example:**

```
pwd
```

**Sample output:**

```
/home/student
```

**What should you notice?**

Linux tells you exactly which directory you are currently working in.

This is useful whenever you are unsure of your current location.

### **2.&#x20;**`ls`**&#x20;— List Directory Contents**

The `ls` command displays files and directories inside a location.

**Syntax:**

```
ls
```

**Example:**

```
ls
```

**Sample output:**

```
Desktop  Documents  Downloads  Music  Pictures
```

Your output may look different depending on your Linux distribution and the files you have.

**What should you notice?**

Each name represents a file or directory inside your current location.

### **3.&#x20;**`ls -l`**&#x20;— Detailed Directory Listing**

The `-l` option displays directory contents in a detailed format.

**Example:**

```
ls -l
```

**Sample output:**

```
total 12
drwxr-xr-x 2 student student 4096 Nov 15 10:30 Documents
drwxr-xr-x 2 student student 4096 Nov 15 10:30 Downloads
drwxr-xr-x 2 student student 4096 Nov 15 10:30 Pictures
```

**What should you notice?**

The output contains additional information, including:

- File type and permission indicators.
- Number of links.
- Owner and group names.
- File size.
- Last modification date.
- File or directory name.

You will learn about permissions and ownership in a later module.

### **4.&#x20;**`ls -a`**&#x20;— Show Hidden Files**

Linux does not normally display hidden files with a standard `ls` command.

The `-a` option displays all entries, including hidden ones.

**Example:**

```
ls -a
```

**Sample output:**

```
.  ..  .bashrc  .profile  Desktop  Documents  Downloads
```

**What should you notice?**

Some entries begin with a dot (`.`).

These are hidden files or special directory entries. We will explore hidden files in Section F.

### **5.&#x20;**`ls -la`**&#x20;— Detailed Listing Including Hidden Files**

You can combine options to get more information.

**Example:**

```
ls -la
```

This displays hidden files along with detailed information.

**Sample output:**

```
total 24
drwxr-xr-x 5 student student 4096 Nov 15 10:30 .
drwxr-xr-x 3 root    root    4096 Nov 14 09:00 ..
-rw-r--r-- 1 student student  220 Nov 14 09:00 .bashrc
-rw-r--r-- 1 student student  807 Nov 14 09:00 .profile
drwxr-xr-x 2 student student 4096 Nov 15 10:30 Documents
```

**What should you notice?**

You can now see both hidden and visible entries, along with their detailed information.

### **6.&#x20;**`cd`**&#x20;— Change Directory**

The `cd` command allows you to move between directories.

**Syntax:**

```
cd directory_name
```

**Example:**

```
cd Documents
```

This moves you into the `Documents` directory, assuming it exists in your current location.

Check your new location:

```
pwd
```

**Sample output:**

```
/home/student/Documents
```

### **7.&#x20;**`cd ~`**&#x20;— Go to Your Home Directory**

You can use:

```
cd ~
```

This takes you directly to the home directory of your current user.

It works regardless of your current location.

### **8.&#x20;**`cd ..`**&#x20;— Move to the Parent Directory**

To move one level upward:

```
cd ..
```

For example, if your current location is:

```
/home/student/Documents
```

After executing `cd ..`, your location becomes:

```
/home/student
```

### **9.&#x20;**`cd /`**&#x20;— Go to the Root Directory**

To navigate to the root directory:

```
cd /
```

Check your location:

```
pwd
```

**Output:**

```
/
```

You are now at the top level of the Linux filesystem.

### **10.&#x20;**`tree`**&#x20;— Display Directory Structure**

The `tree` command displays directories and their contents in a tree-like structure.

**Example:**

```
tree
```

**Sample output:**

```
.
├── Desktop
├── Documents
│   ├── notes.txt
│   └── projects
├── Downloads
└── Pictures
```

This makes it easier to understand how directories are organized.

**What if&#x20;**`tree`**&#x20;is not installed?**

Some Linux distributions do not include it by default.

On Debian or Ubuntu-based systems, you can install it using:

```
sudo apt install tree
```

Installation is optional. You can complete this module without it.

## **E. Finding Files and Directories**

Sometimes you know the name of a file but don't know where it is located.

Linux provides commands that help you search for files and directories.

We will introduce two basic commands.

### **1.&#x20;**`find`**&#x20;— Search for Files and Directories**

The `find` command searches for files and directories within a specified location.

**Basic syntax:**

```
find location -name "filename"
```

**Example:**

Suppose you want to find a file named `notes.txt` inside your home directory.

Execute:

```
find ~ -name "notes.txt"
```

**Possible output:**

```
/home/student/Documents/notes.txt
```

This tells you where Linux found the file.

You can also search for a directory by its name:

```
find ~ -name "Documents"
```

**What should you notice?**

The command searches through the specified directory and its subdirectories.

The search may take longer if the location contains many files.

### **2.&#x20;**`locate`**&#x20;— Search Using an Indexed Database**

The `locate` command searches for files using a previously created database of file locations.

**Example:**

```
locate notes.txt
```

**Possible output:**

```
/home/student/Documents/notes.txt
```

Unlike `find`, which searches through the specified directory structure, `locate` generally searches its database.

**Important:** `locate` may not be installed on your Linux distribution. Its database may also be outdated, so recently created files might not appear in search results.

You can complete this module without using `locate`.

## **F. Understanding Hidden Files**

You may have noticed filenames such as:

```
.bashrc
.profile
```

These are examples of hidden files in Linux.

### **What Are Hidden Files?**

In Linux, filenames that begin with a dot (`.`) are treated as hidden by many standard directory-listing tools.

For example:

```
.bashrc
.profile
.config
```

These files are not normally displayed when you execute:

```
ls
```

However, you can display them using:

```
ls -a
```

### **Why Does Linux Use Hidden Files?**

Hidden files are commonly used to keep certain files and directories out of ordinary directory listings.

They often contain user-specific settings, application configuration, and other supporting information.

For example:

| Hidden file | Basic purpose                                                           |
| ----------- | ----------------------------------------------------------------------- |
| `.bashrc`   | A user-specific Bash configuration file.                                |
| `.profile`  | A user-specific login initialization file.                              |
| `.config`   | Commonly used to store application configuration directories and files. |

You don't need to understand how these files work yet.

For now, remember:

- Hidden files begin with a dot.
- Standard `ls` does not normally display them.
- `ls -a` displays hidden files.

**Quick demonstration**

**Normal listing**

ls

```
Documents  Downloads  Pictures
```

**Listing with hidden files**

ls -a

```
.  ..  .bashrc  .profile  Documents  Downloads  Pictures
```
