# **Module 03 — File and Directory Management**

## **A. Welcome to File and Directory Management**

In the previous module, you learned how to navigate the Linux filesystem and explore directories.

Now it's time to learn how to manage files and directories directly from the terminal.

Think about your computer as an office:

- Directories are filing cabinets.
- Files are documents stored inside those cabinets.
- Copying creates another version of a document.
- Moving places a document somewhere else.
- Renaming changes its name.
- Deleting removes documents you no longer need.

Linux provides simple commands for performing these operations.

File management is particularly important in cybersecurity because you will frequently work with:

- Scripts and tools.
- Configuration files.
- System logs.
- Downloaded files.
- Security reports.
- Challenge files during CTF competitions.

By the end of this module, you will be able to create, organize, edit, copy, move, and remove files using the Linux terminal.

Let's get started.

## **B. Creating Files and Directories**

Linux provides several commands for creating files and directories.

Let's begin with three essential commands.

### **1.&#x20;**`touch`**&#x20;— Create Files**

The `touch` command creates an empty file if it doesn't already exist.

**Syntax:**

```
touch filename
```

**Example:**

```
touch notes.txt
```

This creates an empty file named `notes.txt` in your current directory.

You can check whether the file exists using:

```
ls
```

**Possible output:**

```
notes.txt
```

You can also create multiple files with one command:

```
touch notes.txt report.txt script.txt
```

This creates three empty files.

**Important to remember**

If a file already exists, `touch` does not erase its contents. It updates the file's timestamps instead.

### **2.&#x20;**`mkdir`**&#x20;— Create Directories**

The `mkdir` command creates a new directory.

**Syntax:**

```
mkdir directory_name
```

**Example:**

```
mkdir projects
```

This creates a directory named `projects`.

Check the result:

```
ls
```

**Possible output:**

```
notes.txt  projects  report.txt  script.txt
```

### **3.&#x20;**`mkdir -p`**&#x20;— Create Nested Directories**

Sometimes you want to create multiple directory levels at once.

For example, imagine you want this structure:

```
projects/
└── cybersecurity/
    └── linux/
```

You can create it with one command:

```
mkdir -p projects/cybersecurity/linux
```

The `-p` option creates missing parent directories automatically.

It also avoids an error if the specified directories already exist.

**What should you notice?**

You don't need to create each directory separately.

## **C. Copying Files and Directories**

Linux uses the `cp` command to copy files and directories.

Copying creates another version of the original. The original file remains in its location.

### **1.&#x20;**`cp`**&#x20;— Copy Files**

**Syntax:**

```
cp source destination
```

**Example:**

Suppose you have a file named `notes.txt` and want to copy it into a directory named `projects`.

Execute:

```
cp notes.txt projects/
```

Now check the directory:

```
ls projects/
```

**Output:**

```
notes.txt
```

The file has been copied into `projects`.

The original `notes.txt` still exists in your current directory.

### **2. Copy a File with a Different Name**

You can also give the copied file a different name.

**Example:**

```
cp notes.txt backup.txt
```

This creates a copy named `backup.txt`.

Check the result:

```
ls
```

**Possible output:**

```
backup.txt  notes.txt  projects
```

Both files exist independently.

### **3.&#x20;**`cp -r`**&#x20;— Copy Directories**

By default, `cp` does not copy directories as ordinary files.

To copy an entire directory and its contents, use the `-r` option.

The `-r` stands for recursive, meaning the command also copies the contents of the directory and its subdirectories.

**Example:**

```
cp -r projects projects_backup
```

This creates a new directory named `projects_backup` containing a copy of `projects`.

**What should you remember?**

| Command               | Purpose                            |
| --------------------- | ---------------------------------- |
| `cp file1 file2`      | Copy a file.                       |
| `cp file1 directory/` | Copy a file into a directory.      |
| `cp -r dir1 dir2`     | Copy a directory and its contents. |

**Important distinction**

`cp` copies a file. It does not remove the original.

After copying, both the original and the copy remain available.

## **D. Moving and Renaming Files**

Linux uses the `mv` command for two operations:

1. Moving files and directories.
2. Renaming files and directories.

You don't need separate commands for these operations.

### **1. Move a File into Another Directory**

**Syntax:**

```
mv source destination
```

**Example:**

Suppose you have a file named `report.txt` and want to move it into `projects`.

Execute:

```
mv report.txt projects/
```

Now check your current directory:

```
ls
```

The file `report.txt` should no longer appear there.

Check the destination:

```
ls projects/
```

You should find:

```
notes.txt  report.txt
```

The file has been moved.

### **2. Rename a File**

You can rename a file using the same `mv` command.

**Example:**

```
mv notes.txt study_notes.txt
```

This changes the filename from `notes.txt` to `study_notes.txt`.

Check the result:

```
ls
```

You should now see:

```
study_notes.txt
```

The original filename is no longer present.

### **3. Move a Directory**

The `mv` command also works with directories.

**Example:**

```
mv projects projects_archive
```

This renames the directory `projects` to `projects_archive` when the destination does not already exist.

You can also move a directory into another directory:

```
mv projects_archive backup/
```

This moves the entire directory into `backup`, assuming that destination directory exists.

**Be careful with&#x20;**`mv`

If a destination file already exists, `mv` can overwrite it in some circumstances. Always check the destination before moving or renaming important files.

**Remember:** `mv` moves or renames. It does not create an additional copy like `cp`.

## **E. Reading Simple Files**

Before editing files, you should know how to display their contents and identify their types.

Two useful commands are `cat` and `file`.

### **1.&#x20;**`cat`**&#x20;— Display File Contents**

The `cat` command displays the contents of a text file in your terminal.

**Syntax:**

```
cat filename
```

**Example:**

Suppose you have a file named `notes.txt`.

Execute:

```
cat notes.txt
```

**Possible output:**

```
Linux Fundamentals
Learning file management
Practicing Linux commands
```

The terminal displays the contents of the file.

### **2.&#x20;**`file`**&#x20;— Identify File Types**

Sometimes a filename doesn't tell you what kind of file you are working with.

The `file` command examines a file and identifies its type based on its contents.

**Syntax:**

```
file filename
```

**Example:**

```
file notes.txt
```

**Possible output:**

```
notes.txt: ASCII text
```

Another example:

```
file image.png
```

**Possible output:**

```
image.png: PNG image data, 800 x 600, 8-bit/color RGB
```

**What should you notice?**

The command helps identify whether a file contains text, image data, executable content, or another recognized format.

This can be useful when investigating unfamiliar files during cybersecurity exercises.

## **F. Editing Text Files Using Nano**

Sometimes you need to create or modify a text file directly from the terminal.

Linux provides several text editors. For beginners, we will use **Nano**.

Nano is a simple terminal-based text editor that allows you to write and edit text without opening a graphical application.

### **1. Open or Create a File**

To open a file using Nano:

```
nano filename
```

**Example:**

```

```

If `notes.txt` already exists, Nano opens it.

If it doesn't exist, Nano opens a new editing buffer that can be saved as `notes.txt`.

## **G. Deleting Files and Directories**

Sometimes you need to remove files or directories that are no longer required.

Linux provides three basic commands for this:

- `rm`
- `rmdir`
- `rm -r`

This section requires special attention because deleting files through the terminal can permanently remove data.

**Important Safety Warning**

Linux's `rm` command generally does not move files into a recycle bin.

Deleted files may be difficult or impossible to recover.

Always check the filename and location before executing a deletion command.

For this lesson, practice only inside the dedicated `module03-practice` directory.

### **1.&#x20;**`rm`**&#x20;— Remove Files**

The `rm` command removes a file.

**Syntax:**

```
rm filename
```

**Example:**

```
rm test.txt
```

This removes the file named `test.txt` from the current directory.

You can check whether it is still present:

```
ls
```

If the deletion succeeded, `test.txt` will no longer appear.

### **2.&#x20;**`rmdir`**&#x20;— Remove Empty Directories**

The `rmdir` command removes an empty directory.

**Syntax:**

```
rmdir directory_name
```

**Example:**

```
rmdir empty_folder
```

This removes `empty_folder` if it contains no files or subdirectories.

If the directory contains something, Linux will display an error.

For example:

```
rmdir: failed to remove 'empty_folder': Directory not empty
```

### **3.&#x20;**`rm -r`**&#x20;— Remove Directories and Their Contents**

What if a directory contains files?

You can use:

```
rm -r directory_name
```

The `-r` option means recursive.

It removes the directory and its contents, including nested directories.

**Example:**

```
rm -r test_folder
```

This removes `test_folder` and everything inside it.

**Important:** This operation can permanently delete multiple files. Only use it when you are certain that the target directory is safe to remove.

You do not need `rm -rf` for this module. Avoid using it as a beginner.

## **H. Basic Wildcards**

Sometimes you want to refer to multiple files without typing every filename individually.

Linux supports wildcard characters for matching filenames.

We will introduce two basic wildcards.

### **1.&#x20;**`*`**&#x20;— Match Zero or More Characters**

The asterisk (`*`) matches zero or more characters in a filename.

Suppose your directory contains:

```
notes.txt
report.txt
image.png
script.sh
```

To list files ending in `.txt`, execute:

```
ls *.txt
```

**Output:**

```
notes.txt  report.txt
```

The wildcard matches both text files.

Another example:

```
ls *.sh
```

This lists filenames ending in `.sh`.

### **2.&#x20;**`?`**&#x20;— Match Exactly One Character**

The question mark (`?`) matches exactly one character.

Suppose your directory contains:

```
file1.txt
file2.txt
file10.txt
fileA.txt
```

Execute:

```
ls file?.txt
```

**Output:**

```
file1.txt  file2.txt  fileA.txt
```

Why doesn't `file10.txt` appear?

Because `?` matches only one character, while `10` contains two characters.

### **Quick Comparison**

| Wildcard | Meaning                 | Example     |
| -------- | ----------------------- | ----------- |
| `*`      | Zero or more characters | `*.txt`     |
| `?`      | Exactly one character   | `file?.txt` |

**Wildcard safety**

Wildcards can match multiple files at once.

Before using a wildcard with a deletion command, inspect which files it matches.

For example, use `ls *.txt` first to see the matching files.
