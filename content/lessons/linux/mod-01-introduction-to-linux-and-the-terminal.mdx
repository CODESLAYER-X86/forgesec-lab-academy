# A. Welcome to Linux

Welcome to FORGESEC Academy!

Before exploring cybersecurity tools, analyzing systems, or investigating networks, you need to understand the environment in which many of these activities take place.

That environment is often **Linux**.

Linux is an operating system family widely used in servers, cloud infrastructure, networking, embedded devices, and cybersecurity.

You will encounter Linux throughout your cybersecurity journey. Security professionals use it to investigate systems, analyze network activity, run security tools, and understand how computers work.

In this module, we will take your first steps into Linux. You will learn what Linux is, meet the terminal, and execute your first commands.

**Our goal is simple: get you comfortable enough to start using the Linux command line independently.**

# B. Understanding Linux

### What is Linux?

Linux is an open-source operating system ecosystem built around the Linux kernel.

An operating system (OS) is the software that manages a computer's hardware and provides an environment in which applications can run.

For example, Windows and macOS are operating systems. Linux provides another widely used option.

Linux is especially popular because it is:

- **Open-source:** Its source code is available for people to inspect, modify, and distribute under its licenses.
- **Flexible:** It can be customized for different devices and purposes.
- **Powerful:** It provides extensive control over system resources and processes.
- **Widely supported:** It is used across servers, cloud platforms, development environments, and security systems.

### What is the Linux Kernel?

The **kernel** is the central component of an operating system.

It acts as a bridge between software and computer hardware.

For example, when an application needs to use memory, communicate with a device, or access a file, the kernel helps manage that interaction.

Think of it this way:

- Operating system: The complete environment that allows you to use a computer.
- Kernel: The central component responsible for managing hardware and essential system resources.

Linux technically refers to the kernel, while a complete Linux-based operating system includes the kernel and other software.

### What is a Linux Distribution?

A Linux distribution, commonly called a *distro*, is a complete operating system built around the Linux kernel.

It combines the kernel with system utilities, software, package management tools, and often a graphical desktop environment.

You do not need to build a Linux operating system yourself. You can install a distribution that already provides everything you need.

Here are three popular examples:

**1. Ubuntu**

A beginner-friendly Linux distribution commonly used for learning, software development, and servers.

**2. Kali Linux**

A Debian-based distribution designed for penetration testing, digital forensics, and security assessments. It includes many security-related tools.

**3. Debian**

A well-established Linux distribution known for stability and its extensive software ecosystem.

These distributions share the Linux kernel foundation, but they differ in their software selections, configurations, and intended uses.

### Why Does Linux Matter in Cybersecurity?

Linux is an important part of the cybersecurity industry.

Security professionals frequently use Linux because it provides:

- Access to powerful command-line utilities.
- Tools for network analysis and security testing.
- Flexibility to configure and inspect systems.
- A convenient environment for programming and automation.
- Access to system information and logs.

For example, a penetration tester might use Kali Linux to assess an authorized target system. A security analyst might use Linux to investigate suspicious system activity.

You will explore these applications later in your cybersecurity journey.

> **Remember:** You do not need to become a Linux expert immediately. Understanding the fundamentals is enough to begin.

# C. Meet the Terminal

Now that you understand what Linux is, let's meet one of the most important parts of working with it: the **terminal**.

### What is a Terminal?

A terminal is an application that allows you to interact with your computer using text-based commands.

Instead of clicking buttons and navigating menus, you type instructions and receive text output.

For example, you can ask Linux to display your username by entering a command.

### What is a Shell?

A shell is a program that reads the commands you enter and interprets them so they can be executed.

It acts as an interface between you and the operating system.

When you type a command into a terminal, the shell processes your input and handles its execution.

### What is Bash?

**Bash** stands for Bourne Again Shell.

It is one of the most widely used shells on Linux systems.

Bash allows users to:

- Execute commands.
- Work with command-line tools.
- Manage their working environment.
- Combine commands and automate tasks.

For now, you only need to understand that Bash is a shell you can use to interact with Linux.

Not every Linux system uses Bash as its default shell, but it is common in Linux environments.

### Understanding the Difference

| Term | Meaning |
|---|---|
| Terminal | The application where you enter commands |
| Shell | The program that interprets your commands |
| Bash | A specific type of shell |

### A Simple Real-World Analogy

Imagine ordering food at a restaurant.

- **You:** The person requesting something.
- **Terminal:** The counter where you place your order.
- **Shell:** The staff member who understands your request and processes it.
- **Operating system:** The larger restaurant operation that handles the work.

This is a simplified analogy, but it helps explain how the components interact.

### Why Do Cybersecurity Professionals Use the Terminal?

The terminal provides direct access to many system utilities and security tools.

For example, instead of navigating through several graphical menus, you can use a command to check your system information.

It is also useful when:

- Working with remote servers.
- Investigating suspicious activity.
- Running security tools.
- Managing systems without a graphical interface.
- Automating repetitive tasks.

You will use the terminal frequently throughout this course.

# D. Your First Linux Commands

It's time to get practical.

Linux commands are instructions that tell your system to perform specific tasks.

We will start with eight simple commands. These commands will help you identify yourself, understand your system, and access documentation.

**Important:** The terminal outputs below are illustrative examples. Your actual results will vary depending on your username, machine, distribution, kernel version, and current time.

### 1. `whoami` — Identify Your Username

The `whoami` command displays the username of the current effective user.

It is useful when checking which account you are currently using, particularly when working with multiple accounts.

**Syntax:**

```bash
whoami
```

**Example:**

```bash
student@linux:~$ whoami
student
```

**Understanding the output:**

The output is `student`, which means the current effective user is named `student`.

Your output will display your own username.

### 2. `pwd` — Find Your Current Directory

The `pwd` command stands for *Print Working Directory*.

It displays the full path of your current working directory (the location you are currently working in).

**Syntax:**

```bash
pwd
```

**Example:**

```bash
student@linux:~$ pwd
/home/student
```

**Understanding the output:**

The output `/home/student` indicates that the current working directory is the `student` user's home directory.

The directory is simply the Linux term for a folder.

You will explore directories in more detail in a later module.

### 3. `hostname` — Identify Your Machine

The `hostname` command displays the hostname assigned to your computer.

A hostname is the name used to identify a machine on a network.

**Syntax:**

```bash
hostname
```

**Example:**

```bash
student@linux:~$ hostname
linux
```

**Understanding the output:**

The machine's hostname is `linux`.

Your computer may have a different hostname, such as `ubuntu`, `kali`, or a custom name.

### 4. `uname -r` — Check Your Kernel Version

The `uname` command displays information about the system.

When used with the `-r` option, it displays the Linux kernel release version.

**Syntax:**

```bash
uname -r
```

**Example:**

```bash
student@linux:~$ uname -r
6.8.0-52-generic
```

**Understanding the output:**

The output identifies the kernel release version.

In this example, the system is running a kernel from the `6.8.0` series with a distribution-specific release identifier.

The exact version depends on your installed Linux system and updates.

### 5. `date` — Display Date and Time

The `date` command displays the system's current date and time.

It is useful when checking timestamps or confirming the system clock.

**Syntax:**

```bash
date
```

**Example:**

```bash
student@linux:~$ date
Sun Nov 15 17:30:00 UTC 2026
```

**Understanding the output:**

The output shows the day, month, date, time, timezone, and year.

Your result will depend on your system clock and timezone settings.

### 6. `clear` — Clear the Terminal

As you execute commands, the terminal gradually fills with previous outputs.

The `clear` command clears the visible terminal display, giving you a cleaner workspace.

**Syntax:**

```bash
clear
```

**Example:**

```bash
student@linux:~$ clear
```

**Understanding the output:**

The terminal display is cleared.

You will usually see a fresh command prompt at the top of the terminal.

> **Important:** `clear` does not delete your previous commands or erase your command history. It only clears the visible terminal display.

### 7. `history` — View Previous Commands

The `history` command displays previously executed commands recorded by your shell.

It is useful when you want to review what you have entered or find a command you used earlier.

**Syntax:**

```bash
history
```

**Example:**

```bash
student@linux:~$ history
  1  whoami
  2  pwd
  3  hostname
  4  uname -r
  5  date
  6  history
```

**Understanding the output:**

Each entry contains a number and a previously recorded command.

The numbers represent the command's position in the displayed history list.

The exact output depends on your shell configuration and previous activity.

### 8. `man` — Read Command Documentation

The `man` command stands for *manual*.

It opens a manual page containing documentation about a command, including its purpose, usage, and available options.

Think of it as an instruction manual built into your Linux environment.

**Syntax:**

```bash
man command_name
```

**Example:**

```bash
student@linux:~$ man whoami
```

A manual page opens with information about the `whoami` command.

You can use the same format to inspect other commands.

**Understanding the output:**

The manual provides information about how a command works and how to use it.

You do not need to memorize everything in a manual. Learn how to find the information you need.

# E. Understanding Command Syntax

Before using more Linux commands, it is important to understand how basic command syntax works.

A command is not always just a single word. It can also include additional information.

Let's look at an example we have already used:

```bash
uname -r
```

This command contains two parts.

| Component | Example | Purpose |
|---|---|---|
| Command | `uname` | Specifies what program to execute |
| Option | `-r` | Changes what information the command displays |

### 1. Commands

A command is the instruction or program you want to execute.

For example:

```bash
whoami
```

Here, `whoami` is the command.

### 2. Arguments

An argument is additional information supplied to a command.

For example:

```bash
man whoami
```

Here:

- `man` is the command.
- `whoami` is the argument telling `man` which manual page to open.

### 3. Options or Flags

An option (sometimes called a flag) changes how a command behaves or what information it displays.

For example:

```bash
uname -r
```

The `-r` option tells `uname` to display the kernel release.

Options commonly begin with a single hyphen (`-`) or two hyphens (`--`).

### 4. Putting Everything Together

Consider this command:

```bash
man uname
```

Its structure is:

- Command: `man`
- Argument: `uname`

Now consider:

```bash
uname -r
```

Its structure is:

- Command: `uname`
- Option: `-r`

> **Remember:** You do not need to memorize every command structure. For now, focus on recognizing the command, its arguments, and its options.

# F. Getting Help

One of the most useful skills in Linux is knowing how to find information independently.

You will not remember every command, and that is completely normal.

Linux provides built-in documentation that can help you understand unfamiliar commands.

### 1. Using `man`

Let's open the manual page for `whoami`.

Enter:

```bash
man whoami
```

A documentation page will open inside the terminal.

You may see sections such as:

- NAME: The command's name and a brief description.
- SYNOPSIS: How the command is written.
- DESCRIPTION: What the command does.
- OPTIONS: Available options and their purposes.

The exact sections depend on the manual page.

### 2. Navigating a Manual Page

Manual pages are commonly displayed using a text viewer.

You can navigate using your keyboard.

| Key | Action |
|---|---|
| Space | Move down one screen |
| b | Move up one screen |
| Up Arrow | Move up one line |
| Down Arrow | Move down one line |
| /word | Search for a word |
| n | Find the next search result |
| q | Exit the manual page |

For example, while viewing a manual page, you can press:

```text
q
```

This exits the manual and returns you to the terminal.

**Tip:** You do not need to read an entire manual page every time. Look for the information relevant to your task.

### 3. Using `--help`

Some commands provide a shorter help message through the `--help` option.

For example:

```bash
bash --help
```

This displays a usage summary and information about Bash options.

Unlike a detailed manual page, the help output is usually shorter and intended as a quick reference.

The availability and exact format of `--help` depend on the program. Not every command supports it.

### Which Should You Use?

| Method | Best Used For |
|---|---|
| `man command_name` | Detailed command documentation |
| `command_name --help` | Quick usage information |

**A useful habit:** When you encounter an unfamiliar command, look for its documentation before using it.
