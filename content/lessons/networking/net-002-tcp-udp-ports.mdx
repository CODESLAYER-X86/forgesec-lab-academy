## What You Will Learn

- Contrast connection-oriented TCP (`SYN`, `SYN-ACK`, `ACK`) against connectionless UDP.
- Interpret listening ports (`22`, `53`, `80`, `443`) and socket states (`LISTEN`, `ESTABLISHED`).
- Audit open local ports safely using `ss`.

## Inspecting Active Sockets

On modern Linux distributions, `ss` replaces legacy `netstat` for fast kernel socket inspection.

```bash
ss -tulnp
```

| Flag | Meaning |
| --- | --- |
| `-t` | Show TCP sockets |
| `-u` | Show UDP sockets |
| `-l` | Show listening sockets only |
| `-n` | Display numeric ports instead of service names |
| `-p` | Show the owning process (requires elevated privileges for other users) |

## Expected Output

```text
Netid State  Recv-Q Send-Q Local Address:Port Peer Address:Port
tcp   LISTEN 0      128    127.0.0.1:5432     0.0.0.0:*
tcp   LISTEN 0      128    0.0.0.0:22         0.0.0.0:*
```

<Callout type="warning" title="Minimize Attack Surface">
Binding internal services like PostgreSQL (`5432`) strictly to `127.0.0.1` prevents external network exposure.
</Callout>

## Summary

Every listening socket represents reachable code. Auditing `ss -tulnp` is one of the fastest ways to verify what your machine exposes.
