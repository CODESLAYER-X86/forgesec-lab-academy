## What You Will Learn

- Explain the difference between `/etc/hosts`, local stub resolvers, recursive resolvers, and authoritative nameservers.
- Query `A`, `AAAA`, `MX`, and `TXT` records using `dig`.
- Spot DNS caching TTLs and resolution mismatches.

## Querying DNS Records Safely

Use `dig` with `+short` for concise answers or omit it to inspect authoritative flags and TTL counters.

```bash
dig example.com A +noall +answer
dig example.com TXT +short
```

## Expected Output

```text
example.com.    300    IN    A    93.184.215.14
```

## Summary

DNS diagnostics help verify connectivity failures, mail-authentication `TXT` records (SPF/DMARC), and unexpected host overrides before blaming higher-layer applications.
