## What You Will Learn

- Distinguish private RFC 1918 IPv4 ranges from public routable addresses.
- Read CIDR notation such as `/24` and `/16` without guessing.
- Inspect local interfaces and routing tables using `ip addr` and `ip route`.

## Understanding IP Addresses and Subnets

Every host on an IPv4 network is assigned a 32-bit address written as four octets, paired with a subnet mask that separates the **network prefix** from the **host identifier**.

```bash
ip addr show
ip route show
```

When two hosts share the same subnet prefix, frames travel directly over Layer 2 (ARP + MAC addresses). When a destination lies outside the local subnet, the kernel forwards the packet to the **default gateway**.

## Expected Output

```text
default via 192.168.1.1 dev eth0 proto dhcp metric 100
192.168.1.0/24 dev eth0 proto kernel scope link src 192.168.1.42
```

<Callout type="info" title="Safety Scope">
Only inspect interfaces, routes, and ARP caches on machines and local networks you own or are explicitly authorized to administer.
</Callout>

## Summary

Understanding prefix lengths and route tables lets you verify whether traffic stays local, exits through a VPN tunnel, or traverses a default gateway.
