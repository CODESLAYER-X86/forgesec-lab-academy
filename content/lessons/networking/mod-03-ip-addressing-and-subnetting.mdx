## Section 01 — What Is an IP Address?

An IP address (Internet Protocol address) is a logical address assigned to a network interface so that devices can communicate using the Internet Protocol.

Imagine sending a parcel to someone.

You need:
- A destination address.
- A way to identify where the parcel should go.
- A delivery system to transport it.
Networking works similarly. Devices use IP addresses to identify source and destination locations for network communication.
Example
192.168.1.10
This is an example of an IPv4 address.

A computer may have multiple IP addresses because it can have multiple network interfaces or address configurations.
IP Address vs MAC Address
These two addresses serve different purposes:
- IP address: A logical network-layer address used to identify a network interface for IP communication.
- MAC address: A link-layer address used for communication on a local network.
Real-life analogy:

Imagine sending a parcel to a building:
- The IP address is like the postal address used to identify the destination.
- The MAC address is like a local delivery identifier used to deliver something within a local delivery area.
Remember: An IP address is like a postal address, not necessarily a permanent identity. It can change depending on network configuration.

## Section 02 — IPv4 and IPv6

There are two major versions of the Internet Protocol: IPv4 and IPv6.
IPv4
IPv4 uses a 32-bit address.

It is commonly written as four decimal numbers separated by dots.

Example:
192.168.1.10
Each section is called an octet and represents 8 bits.

An octet can have values from 0 to 255.

IPv4 has approximately 4.3 billion possible addresses, although some are reserved for special purposes.

Real-life analogy:

IPv4 is like a city that has a limited number of house addresses. As the city grows, available addresses become insufficient.
IPv6
IPv6 was developed to provide a much larger address space.

It uses 128-bit addresses and is written in hexadecimal notation.

Example:
2001:db8::1
IPv6 addresses use colons instead of dots. Consecutive groups of zeros can be shortened using :: under IPv6 formatting rules.

Real-life analogy:

Imagine replacing an old address system with a vastly larger system capable of accommodating billions of new neighborhoods and homes.
IPv4 vs IPv6

| Feature | IPv4 | IPv6 |
| --- | --- | --- |
| Address size | 32 bits | 128 bits |
| Format | Decimal | Hexadecimal |
| Separator | Dot (.) | Colon (:) |
| Example | 192.168.1.10 | 2001:db8::1 |
| Address space | Approximately 4.3 billion | Approximately 3.4 × 10³⁸Remember: IPv4 uses 32 bits; IPv6 uses 128 bits. |

## Section 03 — Public and Private IP Addresses

Not every IP address is directly reachable from the public Internet.

There are two important IPv4 address categories: private IP addresses and public IP addresses.
Private IP Addresses
Private IP addresses are used inside local networks, such as homes, universities, and offices.

The three private IPv4 ranges are:

| Range | CIDR |
| --- | --- |
| 10.0.0.0 – 10.255.255.255 | 10.0.0.0/8 |
| 172.16.0.0 – 172.31.255.255 | 172.16.0.0/12 |
| 192.168.0.0 – 192.168.255.255 | 192.168.0.0/16Example: |

192.168.1.10
Real-life analogy:

Your home has room numbers that help family members identify each other. Those room numbers do not need to be unique across the entire world.

Private IP addresses can be reused in different private networks.
Public IP Addresses
Public IP addresses are globally routable addresses used for communication across the Internet.

Your Internet Service Provider (ISP) typically provides public connectivity to your home network.

Real-life analogy:

Your home's postal address is used by external delivery services to find your house, while room numbers are only meaningful inside your home.
Quick Comparison

| Private IP | Public IP |
| --- | --- |
| Used inside private networks | Globally routable |
| Can be reused in different networks | Must be globally coordinated |
| Not directly routed across the public Internet | Used for Internet routingImportant: Private IP addresses are not directly routed across the public Internet. A router commonly uses NAT (Network Address Translation) to allow private-network devices to communicate externally. |

For example, several devices in a home may use private IP addresses while sharing one public IPv4 address through the router.

## Section 04 — Static and Dynamic IP Addresses

An IP address can be assigned in different ways.
Static IP Address
A static IP address is configured to remain consistent rather than being automatically changed through ordinary dynamic assignment.

Common uses include:
- Servers.
- Network infrastructure.
- Printers.
- Devices requiring predictable addressing.
Real-life analogy:

You always live at the same registered address. People know where to find you.
Dynamic IP Address
A dynamic IP address is assigned automatically, commonly through DHCP (Dynamic Host Configuration Protocol).

The address may change over time depending on the network configuration and lease.

Common uses include:
- Home computers.
- Smartphones.
- University Wi-Fi networks.
- Guest devices.
Real-life analogy:

A hotel gives you a room for your stay. You may receive a different room on another visit.
Static vs Dynamic

| Static | Dynamic |
| --- | --- |
| Manually or administratively configured | Commonly assigned through DHCP |
| Predictable address | Can change |
| Useful for stable services | Convenient for everyday devicesRemember: Static means predictable; dynamic means automatically assigned and potentially changing. |

## Section 05 — Subnet Masks

A subnet mask identifies which part of an IPv4 address represents the network and which part represents the host.

Let's use this example:
IP Address:  192.168.1.10
Subnet Mask: 255.255.255.0
The subnet mask tells the computer which devices belong to its local IP network.
Real-Life Analogy
Imagine a university address system:
- City = Network.
- Building = Subnetwork.
- Room = Host.
The address hierarchy helps identify where someone belongs.
Understanding the Mask
An IPv4 address contains 32 bits.

A subnet mask uses:
- 1 bits to identify the network portion.
- 0 bits to identify the host portion.
Example:
IP Address:
11000000.10101000.00000001.00001010

Subnet Mask:
11111111.11111111.11111111.00000000
The first 24 bits represent the network portion, and the last 8 bits represent the host portion.

This is why the address belongs to a /24 network.

Remember: The subnet mask helps a device determine whether a destination is local or needs to be reached through a router.

## Section 06 — CIDR Notation

CIDR stands for Classless Inter-Domain Routing.

It provides a shorter way to represent an IP address and its network prefix.

For example:
192.168.1.10/24
Here:
- 192.168.1.10 = IP address.
- /24 = 24 network bits.
- Remaining 8 bits = host portion.
Common CIDR Examples

| CIDR | Subnet mask | Total addresses |
| --- | --- | --- |
| /8 | 255.0.0.0 | 16,777,216 |
| /16 | 255.255.0.0 | 65,536 |
| /24 | 255.255.255.0 | 256 |
| /25 | 255.255.255.128 | 128 |
| /26 | 255.255.255.192 | 64 |
| /27 | 255.255.255.224 | 32 |
| /28 | 255.255.255.240 | 16 |
| /30 | 255.255.255.252 | 4For traditional IPv4 subnets, two addresses are normally unavailable for ordinary host assignment: |

- Network address: Identifies the subnet.
- Broadcast address: Used to send traffic to all hosts on that IPv4 subnet.
For example, a /24 subnet has 256 total addresses and normally 254 usable host addresses.

There are special cases, such as /31 point-to-point networks and /32 host routes.

Real-life analogy:

CIDR is like specifying how many floors and rooms belong to a particular building instead of writing the entire building layout every time.

## Section 07 — Network Address, Broadcast Address and Host Addresses

Let's examine this network:
192.168.1.0/24
It has three important address categories.
1. Network Address
192.168.1.0
This identifies the network itself.

Think of it as the name of a neighborhood.
2. Broadcast Address
192.168.1.255
This is used to send traffic to all hosts on that IPv4 subnet.

Think of it as making a public announcement to everyone in the neighborhood.
3. Host Addresses
192.168.1.1
192.168.1.2
192.168.1.3
...
192.168.1.254
These addresses can normally be assigned to individual devices.

Think of each host address as a separate house number.
Important Distinction: Gateway vs Network Address
Do not confuse the network address with the gateway address.

A gateway is normally a host address configured on a router interface.

For example:
- Network address: 192.168.1.0
- Possible gateway address: 192.168.1.1
- Example device address: 192.168.1.10
- Broadcast address: 192.168.1.255
The gateway address is configured by the network administrator or network setup. It is not automatically required to be .1.

## Section 08 — Introduction to Subnetting

Subnetting is the process of dividing a larger IP network into smaller networks called subnets.
Why Do We Need Subnetting?
- Organize large networks.
- Separate departments.
- Reduce unnecessary broadcast traffic.
- Manage IP address allocation.
- Improve network segmentation.
Real-Life Analogy
Imagine a large university campus.

Instead of treating the entire campus as one giant building, you divide it into separate departments:
- Computer Science.
- Business Administration.
- Electrical Engineering.
- Library.
Each department can have its own network.
A Simple Subnetting Example
Suppose we have:
192.168.1.0/24
We want to divide this network into four equal-sized subnets.

We borrow 2 bits from the host portion.

Why 2 bits?

[
2^2 = 4  subnets
]

The new prefix becomes:

[
/24 + 2 = /26
]

Each /26 subnet contains:

[
2^(32-26)=64  addresses
]
Four Resulting Subnets

| Subnet | Network address | Usable host range | Broadcast |
| --- | --- | --- | --- |
| 1 | 192.168.1.0 | 192.168.1.1 – 192.168.1.62 | 192.168.1.63 |
| 2 | 192.168.1.64 | 192.168.1.65 – 192.168.1.126 | 192.168.1.127 |
| 3 | 192.168.1.128 | 192.168.1.129 – 192.168.1.190 | 192.168.1.191 |
| 4 | 192.168.1.192 | 192.168.1.193 – 192.168.1.254 | 192.168.1.255Each subnet has 64 total addresses, including 62 traditionally usable host addresses. |

The Three Formulas to Remember
Number of subnets created by borrowing bits:

[
2^n
]

Total addresses per subnet:

[
2^h
]

Normally usable host addresses:

[
2^h-2
]

Where:
- (n) = borrowed host bits.
- (h) = remaining host bits.
Try This Example
You have a /24 network and borrow 3 bits.
- Number of subnets: (2^3=8).
- New prefix: /27.
- Host bits remaining: 5.
- Total addresses per subnet: (2^5=32).
- Normally usable host addresses: (32-2=30).
Memory trick: Borrowed bits determine how many neighborhoods you create. Remaining bits determine how many addresses fit inside each neighborhood.

## Section 09 — Practical Linux Exploration

Now let's inspect your own network configuration.

Open the Linux terminal.
Task 1: Find Your IP Address
ip addr
Look for:
- Interface name.
- IPv4 address.
- CIDR prefix.
Example:
inet 192.168.1.10/24
Here, your interface has IP address 192.168.1.10 with a /24 prefix.
Task 2: Identify Your Network Interfaces
ip link
This displays network interfaces and their link states.
Task 3: Inspect the Routing Table
ip route
Look for:
default via 192.168.1.1
This indicates the default gateway.
Task 4: Check Connectivity
ping -c 4 192.168.1.1
Replace the example address with your actual gateway.

This tests whether your machine can communicate with its gateway using ICMP.
Task 5: Check Your Public IP
You can use a browser to visit:

https://icanhazip.com

Compare the result with your local IP address.

They may differ because your router may use NAT.

Safety note: Do not publish your public IP address, internal network details, or screenshots containing personal information.
